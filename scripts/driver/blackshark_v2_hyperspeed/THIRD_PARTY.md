# Credits and provenance

The C transport and tests were written for OpenRazer with Codex assistance.
Protocol layout, register definitions, gain encoding and EQ-latch sequencing
were derived from and cross-checked against the reference projects below.
Their MIT notices are retained here. No vendor firmware, binaries or private
capture archives are included.

Alexandre Fournier's existing GPL-2.0-or-later fork was compared at `9f3a3ac2`.
In particular, commit `d7067eb1` identified reply status byte 1, which this
implementation adopted after confirming captured hardware replies. No commits
or complete source files were copied from that fork. See COMPARISON.md.
